Treat native functions as unchecked: a bad index can crash the game.
- [2026-10-04] (meta) Game.GetGameSpeedType does not exist in InGame; use GameConfiguration.GetGameSpeedType(), which returns a hash - match it against GameInfo.GameSpeeds rows' Hash.
- [2026-10-04] (units) UnitManager.GetActivityType(unit) returns a value of the ActivityTypes enum (ACTIVITY_AWAKE, ACTIVITY_SLEEP, ACTIVITY_SENTRY, ACTIVITY_OPERATION, ...); there is no GameInfo table for activities - name it by reverse lookup over ActivityTypes.
- [2026-10-04] (research) Choosing research or a civic with PlayerOperations.VALUE_EXCLUSIVE replaces the player's whole queue (a test wiped a 7-civic plan). The tech/civics trees send the full path (GetResearchPath(hash) / GetCivicPath(hash)); VALUE_APPEND adds to the queue. Read the queue with GetResearchQueue() / GetCivicQueue() (values are row indices). set_research/set_civic mode=front keeps the old queue.
